# Pilot attempt record template

Copy this into a new local record for an actual consented observation. Empty
fields are missing evidence, not passes. Keep identifying details and raw host
transcripts private; share a sanitized record only with the participant's consent.
Do not include credentials, account IDs, private journals or unrelated workspace
paths. See the [pilot protocol](../pilot.md) for timing and acceptance rules.

## Optional follow-up observations

Record each reproduction as its own attempt: seed, date, pinned revisions,
environment, exact commands/exits, input/output hashes, source/gap checks,
discrepancies, help and reviewer. Label current public-feed observations separately.

For a contribution: user task, author relationship, PR/check/review links,
observed improvement, active work time, review-wait time, reviewer effort and
actual merge result. Leave absent work explicitly not attempted.
